{% comment %} Home Sketch Index A compact, table-of-contents style list of every sketch — one row per page, title plus a one-line gloss, grouped by section. It sits near the bottom of the home page so a reader who has scrolled that far can see the whole collection at once and jump straight into a sketch. Deliberately lighter than nav/card-list.html (the boxes on the section index pages): no thumbnails, no meta column, one line per sketch. The heading belongs to the calling page (an `##` in index.md), not to this include — the include renders only the grouped rows. Usage: {% include nav/home-sketch-index.html %} {% include nav/home-sketch-index.html sections="/teaching/,/research/,/policy/" %} Parameters: - sections: comma-separated folder list, in the order they should appear. Defaults to "/research/" — the same pair nav/home-tag-cloud draws from. A folder listed here needs a matching accent class in the "Home sketch index" block of cards.css. Front matter each row reads: title — the row label (required) summary — the one-line gloss (optional; the row still renders without) card_order — sort position, as on the section index pages listed — `false` keeps a page out of the list {% endcomment %} {% assign index_sections = include.sections | default: "/research/" | split: "," %}
